# Solicitações de acesso

## T05 — Pedido individual

A tela **Meu acesso** permite solicitar acesso com justificativa opcional e consultar a decisão. A API obtém o autor do token Google verificado pelo Firebase. Uma transação preserva o primeiro pedido quando duas requisições chegam juntas. O servidor usa o banco dedicado `cf-ai-gateway` e as regras impedem acesso direto pelos clientes.

Os testes de interface verificaram envio vazio, atualização da decisão e recuperação após falha de consulta. O ensaio nos emuladores terminou com “Acesso opcional, reenvio concorrente e isolamento de contas OK.” O gate completo terminou com “Validação concluída.” A criação do banco no ambiente publicado pertence à entrega de infraestrutura de homologação.
