# T09 — Previsão de orçamento

Em `/comparar`, uma seleção completa permite consultar a previsão. A Function verifica a identidade e a aprovação, consulta o painel e desconta reservas e gastos da cota mensal de US$ 5. Em caso de bloqueio, o usuário vê o motivo. A consulta é gratuita e não grava reservas.

O servidor calcula em milionésimos de USD, arredondando o teto de cada chamada para cima. Uma comparação inclui uma chamada por modelo e uma por juiz. A repetição de uma geração inclui o painel completo. Cache prevê duas chamadas cobradas e fallback prevê os dois destinos. Os fluxos de repetição e de demonstração usarão esses planos quando integrados.

O limite conservador de entrada usa a janela completa de cada modelo, inclusive para os juízes. A saída é limitada a 512 tokens por geração e 1.024 por parecer. Os adaptadores precisam aplicar esses limites e despachar uma vez por tentativa orçada. Fontes das janelas: [Llama](https://developers.cloudflare.com/workers-ai/models/llama-3.3-70b-instruct-fp8-fast/), [Mistral](https://developers.cloudflare.com/workers-ai/models/mistral-small-3.1-24b-instruct/) e [Qwen](https://developers.cloudflare.com/workers-ai/models/qwen2.5-coder-32b-instruct/).

Para imagem, o cálculo soma os blocos de 512 × 512 e os passos. A homologação de FLUX.1 confirmou a geração, mas o contrato publicado não oferece limites de largura e altura configuráveis. Essa versão fica bloqueada para execução com cota até haver um teto verificável. Um painel ausente também impede liberar a previsão. [Parâmetros de FLUX.1](https://developers.cloudflare.com/workers-ai/models/flux-1-schnell/).
